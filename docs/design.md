# 结构与时钟

当前数据链为：三片 SN74HC165 → 三路同步读取 → 21 键独立消抖 → 21 路独立相位/4096 点正弦 ROM/ADSR/DSP → 流水线加法树 → 固定增益和饱和 → PT8211。

扫描、消抖和 `keys[20:0]` 均保持 SW1～SW21 的原始物理顺序。音符对应关系只由 `notes.hex` 的 21 个频率字排列决定，不增加按键重排逻辑，也不改变 SN74HC165 的 H、G→A 读取顺序。

顶层直接实例化 Gowin `OSC`，`FREQ_DIV=4`，标称处理时钟 52.5MHz。全部业务逻辑使用同一个时钟和采样使能，不使用 V13、MS5351 或 FPGA PLL。PT8211 发送器每 1024 拍产生一个采样节拍，标称约 51.26953125kHz。

默认 ADSR 为 51/2563/32768/5127，约对应 Attack 1ms、Decay 50ms、Sustain 50%、Release 100ms。键盘整帧周期标称 1ms，移位时钟约 100kHz，连续 3 帧消抖。

`rom/notes.hex` 按 `52.5MHz/1024` 的标称采样率和 A4=440Hz 生成。内部 OSC 偏差会同比影响采样率和音高。

当前顶层固定选择 `audio_core.PT_MODE=1`。PT8211 使用 16 位右对齐格式，左右声道发送相同混音样本。标准 I²S 模块仅保留源码，不在顶层实例化。

T18 的 `dbg_err` 只汇总键盘 H 位错误、混音削顶、PT8211 欠载或覆盖；内部 OSC 版没有 MS5351 初始化故障输入。S4 复位会清除该错误锁存。

`dbg_ref` 为内部 OSC /1024，标称约 51.2695kHz；`dbg_lock` 固定为高，用于表明本版没有外部 PLL 锁定条件。

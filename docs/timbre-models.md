# 音色模型与参数来源

本工程的音频仍由 FPGA 对每个采样点实时计算；ROM 中只保存一个周期的数学波形，
不含乐曲、音符录音或预录 PCM。当前采样率为 51.2 kHz，21 个声部并行。

## 为什么不再只改一组谐波系数

真实乐器的频谱会随发音时间变化。旧版四种音色各只有一张静态表，因此即使某一时刻的
谐波比例接近，持续发音时仍容易像“蜂鸣器换波形”。新版每种音色保存起音谱和琴体谱，
`voice.v` 在按键后约 80 ms 内逐采样交叉渐变；钢琴另外使用快慢两项衰减之和。

## 0：正弦基准

起音表和琴体表均为单一基频。它用于检查音高、响度补偿和模拟输出链路，不冒充真实乐器。

## 1：Hammond 拉杆风琴

- 来源：Hammond SKX PRO 官方手册的九拉杆定义与 `Harmonic Diapason 8'`
  注册 `00 8877 760`。
- 拉杆 8、4、2⅔、2、1⅗、1⅓ 英尺分别对应基频及 2～6 次谐波；该注册前两个
  非整数／次谐波拉杆均为 0，适合一周期波表。
- 每级按约 3 dB 换算为线性幅度，得到 H1～H6：
  `1, 1, 0.7079, 0.7079, 0.7079, 0.5012`。
- 风琴是持续激励，故按住时保持满幅，不进行钢琴式自然衰减。

## 2：Karplus–Strong 拨弦乐器

- 来源：Karplus–Strong／数字波导拨弦模型，并参考 Stanford STK 的 `Plucked`
  类实现方式。
- 每个按键有一条独立的 16 位、最大 512 点延迟线。按下时以经过二点平均的 LFSR
  噪声填充有效弦长；随后每个采样点读取弦状态，经二点平均和损耗后写回。
- 延迟长度按 `round(51200/f-0.5)` 分别计算；减去的 0.5 点补偿反馈平均滤波器自身
  引入的半采样延迟。21 个音符使用 51～391 点延迟。
- 按住时环路损耗约为 `1-1/256`；松键后增大为 `1-1/8`，模拟手指／制音器触弦。
  当连续状态低于 8 LSB 时停止环路，避免极低电平的定点极限环。
- 激励填充在 52.5 MHz 系统时钟域完成，最长 391 点只需约 7.45 μs；音频通路仍
  每采样实时更新，没有预录 PCM。

## 3：钢琴简化模态模型

- 来源：公开项目 `danielpodrazka/piano` 的 `generate_grand_piano.py`。采用 C4 标定值
  `b1=1.1 s^-1`、`b2=2.7e-4 s`、弦长 `L=0.62 m`，以及锤击接触时间、击弦位置、
  soundboard bridge-hill 和频率相关衰减公式。
- 低八度使用按 C3 参数计算的独立频谱，中高音区使用 C4 参数，不再让一张 C4
  波表整体降频冒充低音钢琴。起音谱取模型 `t=0`；琴体谱取 `t=160 ms`，硬件在约 80 ms 内交叉渐变，使高次
  泛音在起音后更快退去。
- 幅度包络为两个指数近似项之和：75% prompt 分量的时间常数约 0.32 s，25%
  aftersound 分量约 2.56 s；松键后分别缩短到约 0.04 s 和 0.16 s。低于约
  -60 dB 时结束尾音，防止定点量化后的单一周期残留长期悬停。
- 工程近似：单周期表只能产生整数谐波，尚未实现
  `f_n=n f_0 sqrt(1+B n^2)` 的逐音非谐性、多弦微失谐、锤击噪声与声板卷积。
  若后续资源允许，应改为分时复用的多模态振荡器，而不是继续猜静态 LUT 系数。

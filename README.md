# Tang Mega NEO 138K 实时多音色合成器

version:2026.9.26

## KEY0 音色切换

底板丝印 KEY0（USER_BUTTON0，FPGA 管脚 AA13）每次按下切换一种音色，
约 10 ms 硬件消抖。KEY1（AB13）降低音量，KEY2（Y12）提高音量；
音量共 8 级（0 级静音），上电默认为 5 级。系统使用约 1.25 ms 的 FPGA
上电复位，不再占用实体按键：

0. 正弦
1. Hammond 拉杆风琴（官方 `00 8877 760` 注册）
2. 拨弦乐器（21 路 Karplus–Strong 独立物理模型）
3. 钢琴简化模态音色（低／中高音区独立频谱、双阶段衰减）

四组音色仍以 `4 x 1024` 个地址打包在 `rom/timbres4.hex` 中，但每个地址
同时保存 16 位起音波形和 16 位琴体波形。钢琴在发音后逐样本完成频谱渐变，
并按低音区和中高音区选用分别计算的模型。音色 2 不读取波表，而是使用噪声
激励、可调延迟线和反馈阻尼逐样本生成拨弦声。修改模型后运行
`python tools/gen_timbres.py` 可重新生成 ROM；参数出处和工程近似见
`docs/timbre-models.md`。

拨弦音色使用与波表音色分离的平坦响度曲线，并按延迟线长度分配环路损耗，
使高低音区具有接近的按住衰减时间；松键后保留约 1 秒量级的余音尾。

21 个音符还带有按音区变化的 Q1.15 键位响度补偿曲线。低八度全部保留
完整幅度，中八度从 55% 平滑衰减至 46%，高八度从 41% 衰减至 31%。
第 5 级默认总增益同步提高，低八度较上一版再提高约 2 dB，中高八度
实际输出基本维持原听感。该曲线位于 `src/synth/synth21.v`。

按键串行输入：OUT2 接 PMOD0 J9-8（R17），OUT3 接 PMOD0 J9-7（P16）。
